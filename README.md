# Your Home 🌼

A cozy Flutter app for managing household chores fairly and transparently.

## Features

- Add, edit, and delete chores
- Assign chores to household members
- Activity history
- Persistent local storage using Hive
- Custom illustrations and UI

## Tech Stack

- Flutter
- Dart
- Hive
